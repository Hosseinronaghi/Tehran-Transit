# تهران ترانزیت | Tehran Transit

نسخه آزمایشی **0.2**، اپلیکیشن Flutter فارسی و راست‌به‌چپ برای نقشه یکپارچه اتوبوس، مترو و BRT تهران.

## امکانات فعلی
- لایه‌های مستقل مترو، BRT، اتوبوس و نقاط تبادل
- نمایش قطعه‌های مسیر مترو و BRT از OpenStreetMap در محل واقعی ترسیم‌شده توسط مشارکت‌کنندگان OSM
- ایستگاه‌های مترو و BRT و نمایش ایستگاه‌های نزدیک از نوع دیگر
- جست‌وجوی خطوط و ایستگاه‌های اتوبوس عادی در دیتابیس محلی
- نمایش شماتیک اتصال ایستگاه‌های اتوبوس عادی، بدون ادعای مسیر خیابانی دقیق

## دریافت APK
[GitHub Actions](../../actions) → **Build Android APK** → اجرای موفق → **Artifacts** → **tehran-transit-apk**.

گردش‌کار هنگام ساخت داده‌های اتوبوس را از [tehran-bus-data](https://github.com/mosayeb-a/tehran-bus-data) و هندسه مترو/BRT را از Overpass / OpenStreetMap دریافت می‌کند. بنابراین ساخت به دسترسی به این سرویس‌ها وابسته است. فایل GeoJSON در مخزن فقط یک مجموعه خالی برای توسعه محلی است؛ فایل واقعی در CI تولید می‌شود.

## محدودیت‌های دقت
- هیچ ادعایی درباره کامل بودن شبکه یا فعال بودن همه خطوط وجود ندارد.
- قطعه‌های مسیر OSM ممکن است ناقص یا نامرتب باشند و نام‌گذاری خطوط همیشه یکسان نیست.
- نقاط تبادل فعلاً بر اساس فاصله هوایی حداکثر ۲۵۰ متر علامت‌گذاری می‌شوند. مسیر پیاده‌روی و ورودی/خروجی ایستگاه‌ها بررسی نشده است.
- نقشه پایه برای بارگذاری کاشی‌های OSM اینترنت می‌خواهد؛ داده خطوط داخل APK قرار می‌گیرد.
- زمان رسیدن زنده و مسیریابی ترکیبی هنوز وجود ندارد.
- این نسخه هنوز روی دستگاه واقعی و با APK موفق تأیید نشده است.
