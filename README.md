# تهران ترانزیت | Tehran Transit

اپلیکیشن آزمایشی Flutter برای نمایش خطوط و ایستگاه‌های اتوبوس تهران با رابط فارسی و راست‌به‌چپ.

## امکانات
- جست‌وجوی خط و ایستگاه
- نقشه OpenStreetMap و نمایش مسیر رفت و برگشت
- پایگاه داده SQLite آفلاین که هنگام ساخت APK از داده عمومی تهیه می‌شود

## ساخت APK
به [GitHub Actions](../../actions) بروید و گردش‌کار **Build Android APK** را اجرا کنید. پس از موفقیت، فایل **tehran-transit-apk** را از بخش Artifacts دانلود کنید.

در این مخزن فایل SQLite حجیم قرار نمی‌گیرد. گردش‌کار در هر ساخت، داده را از [tehran-bus-data](https://github.com/mosayeb-a/tehran-bus-data) دریافت و دیتابیس را با `scripts/build_database.py` تولید می‌کند. در نتیجه ساخت به دسترسی GitHub و در دسترس بودن منبع وابسته است.

**وضعیت:** نسخه 0.1 آزمایشی است؛ اجرای موفق APK و دقت تمام خطوط هنوز تأیید نشده. مسیرها خطوط مستقیم بین ایستگاه‌ها هستند و زمان رسیدن زنده وجود ندارد.
