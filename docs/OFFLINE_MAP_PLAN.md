# رها تهران — نقشه اختیاری آفلاین تهران

## تصمیم قطعی محصول (۱۹ نوامبر ۲۰۲۶)

**برنامه باید سبک نصب شود. هیچ بسته کامل نقشه خیابان‌های تهران داخل APK قرار نمی‌گیرد.**

- در اولین اجرای برنامه، نقشه زمینه خیابان‌ها **آنلاین** بارگذاری می‌شود، اگر اینترنت وجود داشته باشد.
- داده مترو، BRT، اتوبوس و موتور مقدماتی مسیریابی از پیش داخل برنامه هستند و بدون اینترنت به کار ادامه می‌دهند.
- کاربری که می‌خواهد خیابان‌ها، پارک‌ها، نام معابر و سایر اجزای نقشه را بدون اینترنت ببیند، از **تنظیمات ← نقشه آفلاین ← «دانلود نقشه تهران برای استفاده آفلاین»** آن را جداگانه دریافت می‌کند.
- **قبل از تأیید کاربر هیچ دانلود حجیمی انجام نمی‌شود.** اندازه فایل قبل از دانلود (اگر ناشر اعلام کرده باشد) و نسخه نقشه نمایش داده می‌شود.
- پس از دانلود موفق و اعتبارسنجی، نقشه خیابان‌های محلی استفاده می‌شود؛ اتصال اینترنت برای نمایش آن ضروری نیست.
- امکان «بررسی نسخه جدید نقشه» و «حذف نقشه آفلاین» وجود دارد؛ حذف نقشه داده ایستگاه‌ها را پاک نمی‌کند.
- یادآوری فصلی، پس از ۹۰ روز داخل صفحه تنظیمات نمایش داده می‌شود. **به‌روزرسانی خودکار یا اجباری وجود ندارد.**

**تفاوت مهم:** بدون اینترنت و پیش از اولین دانلود، داده‌های ایستگاه و خطوط همچنان نمایش‌پذیرند، اما نقشه پایه خیابانی کامل در دسترس نیست. این نتیجه آگاهانه انتخاب APK سبک است.

## پیاده‌سازی موجود

- فایل‌های `lib/offline_map.dart` و `lib/raha_settings.dart` برای خواندن نقشه رستری `MBTiles` از فضای داخلی، دریافت دستی آن از HTTPS، مقایسه SHA-256، تأیید قالب و نسخه، پیشرفت و لغو دانلود، حذف و یادآوری فصلی فراهم شده‌اند.
- یک فایل فهرست انتشار HTTPS مستقل از APK، امکان عرضه نسخه جدید نقشه در هر فصل بدون نصب مجدد اپ را می‌دهد؛ فهرست فقط بعد از اقدام کاربر بررسی می‌شود.
- **بسته واقعی نقشه تهران منتشر شده است**: [GitHub Release نقشه تهران](https://github.com/Hosseinronaghi/Tehran-Transit/releases/tag/tehran-offline-maps). فایل `tehran-2026-Q4-r3.mbtiles` حدود ۳۷ مگابایت است؛ `manifest.json` نیز شامل SHA-256، نشانی، حجم و نسخه است. گزینه دانلود در تنظیمات پس از بررسی فهرست انتشار فعال می‌شود. دسترسی به GitHub برای دانلود لازم است.
- فرمت فعلی رستری است؛ هر ادعا درباره حداقل حجم نصب نقشه نیاز به اندازه‌گیری فایل تولیدشده دارد. در آینده برای حجم بهتر می‌توان موتور برداری با PMTiles/MapLibre را پس از آزمون فنی بررسی کرد.

## تولید و انتشار قانونی بسته نقشه

۱. داده OSM مجاز را از [Geofabrik](https://download.geofabrik.de/asia/iran.html) یا منبع معتبر با مجوز مناسب تهیه و بر محدوده تهران و حاشیه مورد نیاز شبکه حمل‌ونقل برش بزنیم.
۲. کاشی‌های رستری `png/jpg/webp` را با ابزار مجاز تولید، به فایل MBTiles فشرده با جدول `metadata` و `tiles` تبدیل و در زوم‌های مورد نیاز اعتبارسنجی کنیم.
۳. فارسی‌بودن نام‌ها، پوشش خیابان‌ها و کیفیت حرکت/زوم را با دستگاه کم‌قدرت آزمایش کنیم؛ اندازه واقعی فایل را ثبت کنیم.
۴. بسته را در نشانی HTTPS پایدار منتشر کنیم؛ SHA-256 واقعی، حجم، تاریخ و نام نسخه (مثل `2027-Q1`) را در فایل JSON فهرست انتشار اعلام کنیم.
۵. متغیر GitHub Actions به نام `RAHA_MAP_MANIFEST_URL` را برای ساخت اپ تنظیم کنیم. سپس فهرست انتشار را هر فصل مستقل از APK به‌روزرسانی کنیم.

**ممنوع:** برداشت انبوه کاشی‌های `tile.openstreetmap.org` برای ذخیره آفلاین. باید از داده خام OSM و ساخت مستقل کاشی یا سرویس دارای مجوز دانلود آفلاین استفاده شود. انتساب `© OpenStreetMap contributors` و الزامات مجوز ODbL برای داده‌ها رعایت شود.
